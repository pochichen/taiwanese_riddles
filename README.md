# 台灣趣味猜謎 (Taiwanese Riddles)

一個簡單、直覺且支援鍵盤操作的台灣趣味猜謎 Web App。收錄了各種傳統與現代的謎語，讓你在輕鬆互動中體驗猜謎的樂趣！

## 開始遊戲

請直接點擊下方連結開始遊戲：
**[開始猜謎遊戲](https://pochichen.github.io/taiwanese_riddles/)**

---

## 操作說明

本 App 針對電腦使用者設計了極簡的「單鍵操作」邏輯，也支援行動裝置點擊。

### ⌨️ 鍵盤操作（推薦）
- **[左鍵 Left]**：
  顯示上一題

- **[右鍵 Right]**：
  顯示下一題

- **[上鍵 Up]**：
  顯示提示

- **[下鍵 Down]**：
  顯示答案

- **[空白鍵 Space]**：
  1. 循環顯示所有提示：逐條顯示題目**提示**（若有）。
  2. 提示顯示完畢後：顯示**正確答案**。
  3. 最後按下：自動跳轉至**下一題**。

### 畫面操作
- 點擊左上「⬅️ 上一題」/ 右上「下一題 ➡️」切換題目。
- 點擊右上「🔤 字體 [小 | 中 | 大]」切換字級，專為電視大螢幕客廳瀏覽與長輩友善閱讀設計（支援記住偏好設定）。
- 點擊左下「💡 提示」按鈕查看提示。
- 點擊右下「🔓 看答案」按鈕顯示答案與由來解析。

### ✨ 特色功能
- **電視與長輩友善**：支援三段字體切換（小/中/大），大字體在客廳大電視上遠距清晰可見。
- **全題臺羅拼音**：題目與答案皆標注教育部臺灣閩南語羅馬字拼音（TL / POJ），方便邊猜邊學正確台語發音。
- **由來與文化解析**：答案揭曉時同步附帶台語激骨話（歇後語）的諧音、雙關與常民器物背景解析。
- **答題進度與狀態**：頂部具備即時題號與進度條，卡片上方附帶思考/提示/解答步驟狀態標籤。

## 技術架構

- **前端**: 原生 JavaScript (Vanilla JS), HTML5, CSS3。
- **資料儲存**: JSON 格式。
- **爬蟲工具**: 使用 Python (BeautifulSoup) 從教育機構網站擷取並整理謎語資料。
- **部署**: GitHub Pages。
